Laboratory Task 1 – Data Profiling using ydata-profiling

Aim

To perform data profiling on a dataset and generate an automated report describing its structure and data-quality characteristics.

Theory

Data profiling is the process of examining a dataset to understand its structure, content and quality before further analysis. It helps identify the number of records and attributes, data types, missing values, duplicate records, unique values, descriptive statistics and distributions. The ydata-profiling library automatically generates a detailed profiling report from a Pandas DataFrame.

Requirements
  • Python 3.x
  • Google Colab or Jupyter Notebook
  • Pandas
  • ydata-profiling
  • CSV dataset
Procedure
  1. Install the required library.
  2. Import Pandas and ydata-profiling.
  3. Load the CSV dataset.
  4. Inspect the dataset.
  5. Generate the profiling report.
  6. Save and examine the HTML report.
Program
!pip install -q ydata-profiling

import pandas as pd
from ydata_profiling import ProfileReport

df = pd.read_csv("dataset.csv")
df.head()

print("Shape:", df.shape)
print("\nData Types:")
print(df.dtypes)

profile = ProfileReport(
    df,
    title="Data Profiling Report",
    explorative=True
)
profile.to_file("data_profiling_report.html")
Expected Output

The report provides an overview of variables, missing values, duplicate records, descriptive statistics, distributions and relationships/correlations where applicable.

Result

The dataset was successfully profiled using ydata-profiling and an automated profiling report was generated.

Viva Questions
What is data profiling?
Examining a dataset to understand its structure, content and quality (records, columns, types, missing values, duplicates, statistics) before analysis.
Why is data profiling performed before analysis?
To find data-quality problems early so that cleaning can be planned and wrong conclusions avoided.
What information can a profiling report provide?
Number of variables and rows, data types, missing cells, duplicate rows, distinct values, descriptive statistics, histograms, correlations and alerts.
What is the purpose of ydata-profiling?
It automatically creates a detailed HTML profiling report from a Pandas DataFrame with one line of code.
Why are missing values and duplicate records important?
Missing values bias statistics and break models. Duplicates over-count records and distort results, so both must be handled before analysis.

Experiment No. 3 – Architectural Design: Solution Architecture

Objectives
  1. To define the overall architecture of a data engineering solution.
  2. To identify the major components and understand the flow of data between them.
  3. To select appropriate technologies and tools for each component.
  4. To design a data pipeline and processing workflow.
  5. To create an architectural diagram to visualize the proposed solution.
  6. To review the architecture based on performance, scalability, reliability, and stakeholder requirements.
Problem Statement

Design a data engineering architecture for a Student Data Analytics System that collects student information from different sources, processes and stores the data, and generates reports for academic analysis. The system should collect student details, attendance records, examination marks, and course information. The collected data must be cleaned, transformed, stored, and made available for analysis and reporting.

Data Engineering Architecture

Solution architecture is the high-level design of a system that describes its major components, technologies, data flow, and interactions. In data engineering, solution architecture defines how data is collected, ingested, processed, stored, and delivered for analysis. A well-designed architecture helps ensure that data is accurate, accessible, secure, and available for decision-making.

Components of a Data Engineering Architecture
  1. Data Sources: Systems from which data is collected, such as relational databases, CSV/Excel files, APIs, and application logs. In this example, the sources are student details, attendance records, examination marks, and course information.
  2. Data Ingestion Layer: Collects data from different sources and transfers it to the processing or storage system. Python scripts or Apache NiFi can be used to ingest data from CSV files and databases.
  3. Data Processing Layer: Cleans, transforms, validates, and integrates collected data. Operations include removing duplicates, handling missing values, standardizing formats, and calculating attendance percentages or average marks. Python with Pandas or Apache Spark can be used.
  4. Data Storage Layer: Stores raw and processed data for future use. Technologies may include MySQL, PostgreSQL, MongoDB, Amazon S3, or HDFS. MySQL or PostgreSQL is suitable for structured student data.
  5. Data Analysis and Visualization Layer: Makes processed data available for analysis and reporting. SQL, Power BI, Tableau, or Python Matplotlib can be used to create reports on student performance, attendance, and course-wise results.
  6. Monitoring and Security Layer: Monitors pipeline execution, records errors, and protects sensitive student information through authentication, access control, logging, and backups.

Laboratory Task 5 – ETL Pipeline using Python and Pandas

Your PDFs didn't include Task 5. This write-up is built from Internal questions 12 and 13. Check it against your class notes.

Aim

To build an ETL (Extract, Transform, Load) pipeline in Python that extracts data from a CSV file, cleans and transforms it, loads it into a destination CSV file, and logs the pipeline execution status.

Theory

ETL stands for Extract, Transform, Load. Extract reads data from a source such as a CSV file or database. Transform cleans and reshapes the data: removing duplicates, handling missing values, standardizing formats and creating derived columns. Load writes the processed data to a destination such as a CSV file, database or data warehouse. Logging records each step's status and errors so that the pipeline can be monitored and debugged.

Requirements
  • Python 3.x
  • Google Colab or Jupyter Notebook
  • Pandas
  • logging module (built in)
  • CSV dataset
Procedure
  1. Import Pandas and logging.
  2. Configure logging.
  3. Extract data from the source CSV file.
  4. Remove duplicate records.
  5. Handle missing values (numeric → mean, text → "Unknown").
  6. Standardize column names and text values; add derived columns.
  7. Load the cleaned data into a destination CSV file.
  8. Log the execution status of each step and of the whole pipeline.
Program – Basic ETL (Q12)
import pandas as pd

# ---------- EXTRACT ----------
df = pd.read_csv("dataset.csv")
print("Extracted data shape:", df.shape)
print("\nMissing values before cleaning:")
print(df.isnull().sum())
print("Duplicate records before cleaning:", df.duplicated().sum())

# ---------- TRANSFORM ----------
# 1. Remove duplicate records
df = df.drop_duplicates()

# 2. Handle missing values
for col in df.columns:
    if pd.api.types.is_numeric_dtype(df[col]):
        df[col] = df[col].fillna(df[col].mean())      # numeric -> mean
    else:
        df[col] = df[col].fillna("Unknown")           # text -> "Unknown"

print("\nMissing values after cleaning:")
print(df.isnull().sum())
print("Duplicate records after cleaning:", df.duplicated().sum())

# ---------- LOAD ----------
df.to_csv("cleaned_dataset.csv", index=False)
print("\nCleaned data shape:", df.shape)
print("Cleaned data saved to cleaned_dataset.csv")
Program – ETL Workflow with Logging (Q13)
import logging
import pandas as pd

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s",
    handlers=[logging.FileHandler("etl_pipeline.log"),
              logging.StreamHandler()],
    force=True
)

def extract(path):
    logging.info("EXTRACT started: reading %s", path)
    df = pd.read_csv(path)
    logging.info("EXTRACT completed: %d rows, %d columns", df.shape[0], df.shape[1])
    return df

def transform(df):
    logging.info("TRANSFORM started")
    before = len(df)
    df = df.drop_duplicates()
    logging.info("Removed %d duplicate rows", before - len(df))

    missing = int(df.isnull().sum().sum())
    for col in df.columns:
        if pd.api.types.is_numeric_dtype(df[col]):
            df[col] = df[col].fillna(df[col].mean())
        else:
            df[col] = df[col].fillna("Unknown")
    logging.info("Filled %d missing values", missing)

    # standardize column names and text values
    df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")
    for col in df.columns:
        if not pd.api.types.is_numeric_dtype(df[col]):
            df[col] = df[col].astype(str).str.strip()

    # example derived attribute (only if the column exists)
    if "pass_percentage" in df.columns:
        df["result_status"] = df["pass_percentage"].apply(
            lambda p: "Good" if p >= 75 else "Needs Attention")
        logging.info("Added derived column result_status")

    logging.info("TRANSFORM completed: %d rows", len(df))
    return df

def load(df, path):
    logging.info("LOAD started: writing %s", path)
    df.to_csv(path, index=False)
    logging.info("LOAD completed: %d rows saved", len(df))

def run_pipeline(source, destination):
    logging.info("===== ETL PIPELINE STARTED =====")
    try:
        data = extract(source)
        data = transform(data)
        load(data, destination)
        logging.info("===== ETL PIPELINE COMPLETED SUCCESSFULLY =====")
    except FileNotFoundError:
        logging.error("Source file not found: %s", source)
        logging.error("===== ETL PIPELINE FAILED =====")
    except Exception as e:
        logging.error("Pipeline error: %s", e)
        logging.error("===== ETL PIPELINE FAILED =====")

run_pipeline("dataset.csv", "transformed_dataset.csv")
Expected Output

The pipeline prints the dataset shape, missing values and duplicate counts before and after cleaning. It saves the cleaned data to a new CSV file and logs messages for EXTRACT, TRANSFORM and LOAD, ending with “ETL PIPELINE COMPLETED SUCCESSFULLY” (or FAILED with the error).

Result

An ETL pipeline was implemented using Python and Pandas. Data was extracted, cleaned, transformed and loaded into a destination CSV file, and the execution status was logged.

Viva Questions
What is ETL?
Extract, Transform, Load: the process of reading data from sources, cleaning/transforming it, and storing it in a destination.
What is the difference between ETL and ELT?
In ETL data is transformed before loading. In ELT raw data is loaded first and transformed inside the warehouse.
How are missing values handled?
Numeric columns are filled with the mean (or median), text columns with a placeholder such as "Unknown", or rows are dropped with dropna().
How are duplicates removed?
With df.drop_duplicates(). df.duplicated().sum() counts them.
Why is logging used in a pipeline?
It records when each step ran, how many rows it processed, and any errors, which helps with monitoring and debugging.
Why use try/except in the pipeline?
So a failure is caught and logged as FAILED with the reason, instead of crashing silently.

import pandas as pd

students = pd.read_csv("students.csv")
attendance = pd.read_csv("attendance.csv")
marks = pd.read_csv("marks.csv")

# Clean
for d in (students, attendance, marks):
    d.drop_duplicates(inplace=True)
students = students.dropna(subset=["student_id"])

# Transform
attendance["attendance_pct"] = (
    attendance["classes_attended"] / attendance["classes_held"] * 100
).round(2)
avg_marks = marks.groupby("student_id", as_index=False)["marks"].mean()
avg_marks = avg_marks.rename(columns={"marks": "average_marks"})

integrated = (
    students
    .merge(attendance[["student_id", "attendance_pct"]], on="student_id", how="left")
    .merge(avg_marks, on="student_id", how="left")
)

Q13 ETL workflow with logging

Implement an ETL workflow that extracts data, cleans and transforms it, loads the result into a destination CSV file, and prints or logs the pipeline execution status.

Python
import logging
import pandas as pd

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s",
    handlers=[logging.FileHandler("etl_pipeline.log"),
              logging.StreamHandler()],
    force=True
)

def extract(path):
    logging.info("EXTRACT started: reading %s", path)
    df = pd.read_csv(path)
    logging.info("EXTRACT completed: %d rows, %d columns", df.shape[0], df.shape[1])
    return df

def transform(df):
    logging.info("TRANSFORM started")
    before = len(df)
    df = df.drop_duplicates()
    logging.info("Removed %d duplicate rows", before - len(df))

    missing = int(df.isnull().sum().sum())
    for col in df.columns:
        if pd.api.types.is_numeric_dtype(df[col]):
            df[col] = df[col].fillna(df[col].mean())
        else:
            df[col] = df[col].fillna("Unknown")
    logging.info("Filled %d missing values", missing)

    # standardize column names and text values
    df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")
    for col in df.columns:
        if not pd.api.types.is_numeric_dtype(df[col]):
            df[col] = df[col].astype(str).str.strip()

    # example derived attribute (only if the column exists)
    if "pass_percentage" in df.columns:
        df["result_status"] = df["pass_percentage"].apply(
            lambda p: "Good" if p >= 75 else "Needs Attention")
        logging.info("Added derived column result_status")

    logging.info("TRANSFORM completed: %d rows", len(df))
    return df

def load(df, path):
    logging.info("LOAD started: writing %s", path)
    df.to_csv(path, index=False)
    logging.info("LOAD completed: %d rows saved", len(df))

def run_pipeline(source, destination):
    logging.info("===== ETL PIPELINE STARTED =====")
    try:
        data = extract(source)
        data = transform(data)
        load(data, destination)
        logging.info("===== ETL PIPELINE COMPLETED SUCCESSFULLY =====")
    except FileNotFoundError:
        logging.error("Source file not found: %s", source)
        logging.error("===== ETL PIPELINE FAILED =====")
    except Exception as e:
        logging.error("Pipeline error: %s", e)
        logging.error("===== ETL PIPELINE FAILED =====")

run_pipeline("dataset.csv", "transformed_dataset.csv")

# --- Explanation ---
- Sources: Academic data comes from several systems: student master data in
  MySQL, and attendance, marks and course files in CSV/Excel.
- Ingestion: Python scripts read each source on a schedule and pass the data on.
- Processing: Pandas validates IDs and types, removes duplicates, fills missing
  values, joins datasets on student_id / subject_code, and computes KPIs such as
  average pass %, total failures, absentees, performance_level and academic_risk.
- Storage: Raw files are kept unchanged for traceability, and the cleaned,
  integrated tables are loaded into MySQL/PostgreSQL.
- Analysis & visualization: SQL queries and dashboards show subject-wise
  results and the subjects that need intervention.
- Orchestration & monitoring: Airflow runs the steps in order and retries
  failures. Logging records each run. Access control protects student data.
- Review criteria: performance (fast queries), scalability (Spark/HDFS when
  data grows), reliability (logging, retries, backups) and stakeholder needs
  (dashboards for faculty and management).

# --- Python (integration step) ---
import pandas as pd

students = pd.read_csv("students.csv")
attendance = pd.read_csv("attendance.csv")
marks = pd.read_csv("marks.csv")

# Clean
for d in (students, attendance, marks):
    d.drop_duplicates(inplace=True)
students = students.dropna(subset=["student_id"])

# Transform
attendance["attendance_pct"] = (
    attendance["classes_attended"] / attendance["classes_held"] * 100
).round(2)
avg_marks = marks.groupby("student_id", as_index=False)["marks"].mean()
avg_marks = avg_marks.rename(columns={"marks": "average_marks"})

# Integrate
integrated = (
    students
    .merge(attendance[["student_id", "attendance_pct"]], on="student_id", how="left")
    .merge(avg_marks, on="student_id", how="left")
)

# Load
integrated.to_csv("student_performance.csv", index=False)
print(integrated.head())
print("Integrated data saved to student_performance.csv")

# ===================== Q13) ETL workflow with logging =====================

# --- Python ---
import logging
import pandas as pd

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s",
    handlers=[logging.FileHandler("etl_pipeline.log"),
              logging.StreamHandler()],
    force=True
)

def extract(path):
    logging.info("EXTRACT started: reading %s", path)
    df = pd.read_csv(path)
    logging.info("EXTRACT completed: %d rows, %d columns", df.shape[0], df.shape[1])
    return df

def transform(df):
    logging.info("TRANSFORM started")
    before = len(df)
    df = df.drop_duplicates()
    logging.info("Removed %d duplicate rows", before - len(df))

    missing = int(df.isnull().sum().sum())
    for col in df.columns:
        if pd.api.types.is_numeric_dtype(df[col]):
            df[col] = df[col].fillna(df[col].mean())
        else:
            df[col] = df[col].fillna("Unknown")
    logging.info("Filled %d missing values", missing)

    # standardize column names and text values
    df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")
    for col in df.columns:
        if not pd.api.types.is_numeric_dtype(df[col]):
            df[col] = df[col].astype(str).str.strip()

    # example derived attribute (only if the column exists)
    if "pass_percentage" in df.columns:
        df["result_status"] = df["pass_percentage"].apply(
            lambda p: "Good" if p >= 75 else "Needs Attention")
        logging.info("Added derived column result_status")

    logging.info("TRANSFORM completed: %d rows", len(df))
    return df

def load(df, path):
    logging.info("LOAD started: writing %s", path)
    df.to_csv(path, index=False)
    logging.info("LOAD completed: %d rows saved", len(df))

def run_pipeline(source, destination):
    logging.info("===== ETL PIPELINE STARTED =====")
    try:
        data = extract(source)
        data = transform(data)
        load(data, destination)
        logging.info("===== ETL PIPELINE COMPLETED SUCCESSFULLY =====")
    except FileNotFoundError:
        logging.error("Source file not found: %s", source)
        logging.error("===== ETL PIPELINE FAILED =====")
    except Exception as e:
        logging.error("Pipeline error: %s", e)
        logging.error("===== ETL PIPELINE FAILED =====")

run_pipeline("dataset.csv", "transformed_dataset.csv")
